# 02 — Ciberseguridad

Cubre el ciclo completo de seguridad ofensiva y defensiva: desde
preparación profesional (entrevistas) hasta forense digital, pasando
por cracking, OSINT, reconocimiento, hacking básico/intermedio y
criptografía. También incluye amenazas emergentes con IA.
