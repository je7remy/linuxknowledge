# Glosario

## 📖 Glosario: Certificado de Ciberseguridad de Google (Curso 7)

### A

- **Absolute file path:** La ruta completa del archivo, que comienza desde la raíz.
    
- **Access controls:** Controles de seguridad que gestionan el acceso, la autorización y la responsabilidad de la información.
    
- **Active packet sniffing:** Un tipo de ataque donde los paquetes de datos son manipulados en tránsito.
    
- **Address Resolution Protocol (ARP):** Un protocolo de red utilizado para determinar la dirección MAC del siguiente router o dispositivo en la ruta.
    
- **Advanced persistent threat (APT):** Una instancia cuando un actor de amenazas mantiene acceso no autorizado a un sistema durante un período prolongado de tiempo.
    
- **Adversarial artificial intelligence (AI):** Una técnica que manipula la inteligencia artificial (IA) y la tecnología de aprendizaje automático (ML) para realizar ataques de manera más eficiente.
    
- **Adware:** Un tipo de software legítimo que a veces se utiliza para mostrar anuncios digitales en aplicaciones.
    
- **Algorithm:** Un conjunto de reglas utilizadas para resolver un problema.
    
- **Analysis:** La investigación y validación de alertas.
    
- **Angler phishing:** Una técnica donde los atacantes se hacen pasar por representantes de servicio al cliente en las redes sociales.
    
- **Anomaly-based analysis:** Un método de detección que identifica comportamientos anormales.
    
- **Antivirus software:** Un programa de software utilizado para prevenir, detectar y eliminar malware y virus.
    
- **Application:** Un programa que realiza una tarea específica.
    
- **Application programming interface (API) token:** Un pequeño bloque de código cifrado que contiene información sobre un usuario.
    
- **Argument (Linux):** Información específica necesaria para un comando.
    
- **Argument (Python):** Los datos introducidos en una función cuando se llama.
    
- **Array:** Un tipo de datos que almacena datos en una lista ordenada separada por comas.
    
- **Assess:** El quinto paso del NIST RMF que significa determinar si los controles establecidos se implementan correctamente.
    
- **Asset:** Un elemento percibido como valioso para una organización.
    
- **Asset classification:** La práctica de etiquetar activos según la sensibilidad e importancia para una organización.
    
- **Asset inventory:** Un catálogo de activos que necesitan ser protegidos.
    
- **Asset management:** El proceso de seguimiento de activos y los riesgos que los afectan.
    
- **Asymmetric encryption:** El uso de un par de claves pública y privada para el cifrado y descifrado de datos.
    
- **Attack surface:** Todas las vulnerabilidades potenciales que un actor de amenazas podría explotar.
    
- **Attack tree:** Un diagrama que mapea amenazas a activos.
    
- **Attack vectors:** Las vías que utilizan los atacantes para penetrar las defensas de seguridad.
    
- **Authentication:** El proceso de verificar quién es alguien.
    
- **Authorization:** El concepto de otorgar acceso a recursos específicos en un sistema.
    
- **Authorize:** El sexto paso del NIST RMF que se refiere a ser responsable de los riesgos de seguridad y privacidad que puedan existir en una organización.
    
- **Automation:** El uso de la tecnología para reducir el esfuerzo humano y manual para realizar tareas comunes y repetitivas.
    
- **Availability:** La idea de que los datos son accesibles para aquellos que están autorizados a acceder a ellos.

### B

- **Baiting:** Una táctica de ingeniería social que tienta a las personas a comprometer su seguridad.
    
- **Bandwidth:** La capacidad máxima de transmisión de datos a través de una red, medida en bits por segundo.
    
- **Baseline configuration (baseline image):** Un conjunto documentado de especificaciones dentro de un sistema que se utiliza como base para futuras compilaciones, lanzamientos y actualizaciones.
    
- **Bash:** El shell predeterminado en la mayoría de las distribuciones de Linux.
    
- **Basic auth:** La tecnología utilizada para establecer la solicitud de un usuario para acceder a un servidor.
    
- **Basic Input/Output System (BIOS):** Un microchip que contiene instrucciones de carga para la computadora y es prevalente en sistemas más antiguos.
    
- **Biometrics:** Las características físicas únicas que se pueden utilizar para verificar la identidad de una persona.
    
- **Bit:** La unidad más pequeña de medida de datos en una computadora.
    
- **Boolean data:** Datos que solo pueden tener uno de dos valores: `True` o `False`.
    
- **Bootloader:** Un programa de software que arranca el sistema operativo.
    
- **Botnet:** Una colección de computadoras infectadas por malware que están bajo el control de un solo actor de amenazas, conocido como el "bot-herder".
    
- **Bracket notation:** Los índices colocados entre corchetes `[]`.
    
- **Broken chain of custody:** Inconsistencias en la recolección y registro de evidencia en la cadena de custodia.
    
- **Brute force attack:** El proceso de prueba y error para descubrir información privada.
    
- **Bug bounty:** Programas que alientan a hackers independientes a encontrar y reportar vulnerabilidades.
    
- **Built-in function:** Una función que existe dentro de Python y se puede llamar directamente.
    
- **Business continuity:** La capacidad de una organización para mantener su productividad diaria estableciendo planes de recuperación de desastres de riesgo.
    
- **Business continuity plan (BCP):** Un documento que describe los procedimientos para sostener las operaciones comerciales durante y después de una interrupción significativa.
    
- **Business Email Compromise (BEC):** Un tipo de ataque de phishing donde un actor de amenazas se hace pasar por una fuente conocida para obtener una ventaja financiera.
    

---

### C

- **Categorize:** El segundo paso del NIST RMF que se utiliza para desarrollar procesos y tareas de gestión de riesgos.
    
- **CentOS:** Una distribución de código abierto que está estrechamente relacionada con Red Hat.
    
- **Central Processing Unit (CPU):** El procesador principal de una computadora, que se utiliza para realizar tareas informáticas generales en una computadora.
    
- **Chain of custody:** El proceso de documentar la posesión y el control de la evidencia durante el ciclo de vida de un incidente.
    
- **Chronicle:** Una herramienta nativa de la nube diseñada para retener, analizar y buscar datos.
    
- **Cipher:** Un algoritmo que cifra información.
    
- **Cloud-based firewalls:** Firewalls de software alojados por el proveedor de servicios en la nube.
    
- **Cloud computing:** La práctica de utilizar servidores remotos, aplicaciones y servicios de red alojados en Internet en lugar de en dispositivos físicos locales.
    
- **Cloud network:** Una colección de servidores o computadoras que almacenan recursos y datos en centros de datos remotos a los que se puede acceder a través de Internet.
    
- **Cloud security:** El proceso de garantizar que los activos almacenados en la nube estén configurados correctamente y que el acceso a esos activos se limite a los usuarios autorizados.
    
- **Command:** Una instrucción que le dice a la computadora que haga algo.
    
- **Command and control (C2):** Las técnicas utilizadas por actores maliciosos para mantener comunicaciones con sistemas comprometidos.
    
- **Command-line interface (CLI):** Una interfaz de usuario basada en texto que utiliza comandos para interactuar con la computadora.
    
- **Comment:** Una nota que los programadores hacen sobre la intención detrás de su código.
    
- **Common Event Format (CEF):** Un formato de registro que utiliza pares clave-valor para estructurar datos e identificar campos y sus valores correspondientes.
    
- **Common Vulnerabilities and Exposures (CVE®) list:** Un diccionario de acceso abierto de vulnerabilidades y exposiciones conocidas.
    
- **Common Vulnerability Scoring System (CVSS):** Un sistema de medición que califica la gravedad de una vulnerabilidad.
    
- **Compliance:** El proceso de adherirse a estándares internos y regulaciones externas.
    
- **Computer security incident response teams (CSIRT):** Un grupo especializado de profesionales de la seguridad capacitados en la gestión y respuesta a incidentes.
    
- **Computer virus:** Código malicioso escrito para interferir con las operaciones de la computadora y causar daño a datos y software.
    
- **Conditional statement:** Una declaración que evalúa el código para determinar si cumple un conjunto específico de condiciones (`if`, `elif`, `else`).
    
- **Confidentiality:** La idea de que solo los usuarios autorizados pueden acceder a activos o datos específicos.
    
- **Confidential data:** Datos que a menudo tienen límites en el número de personas que tienen acceso a ellos.
    
- **Confidentiality, integrity, availability (CIA) triad:** Un modelo que ayuda a informar cómo las organizaciones consideran el riesgo al configurar sistemas y políticas de seguridad.
    
- **Configuration file:** Un archivo utilizado para configurar los ajustes de una aplicación.
    
- **Containment:** El acto de limitar y prevenir daños adicionales causados por un incidente.
    
- **Controlled zone:** Una subred que protege la red interna de la zona no controlada.
    
- **Cross-site scripting (XSS):** Un ataque de inyección que inserta código en un sitio web o aplicación web vulnerable.
    
- **Crowdsourcing:** La práctica de recopilar información utilizando la participación y colaboración pública.
    
- **Cryptographic attack:** Un ataque que afecta las formas seguras de comunicación entre un remitente y un destinatario previsto.
    
- **Cryptographic key:** Un mecanismo que descifra el texto cifrado.
    
- **Cryptography:** El proceso de transformar información en una forma que los lectores no deseados no puedan entender.
    
- **Cryptojacking:** Una forma de malware que instala software para minar criptomonedas ilegalmente.
    
- **CVE Numbering Authority (CNA):** Una organización que se ofrece voluntariamente para analizar y distribuir información sobre CVE elegibles.
    
- **Cybersecurity (or security):** La práctica de garantizar la confidencialidad, integridad y disponibilidad de la información protegiendo redes, dispositivos, personas y datos contra el acceso no autorizado o la explotación criminal.

### D

- **Data:** Información que es traducida, procesada o almacenada por una computadora.
    
- **Data at rest:** Datos que no están siendo accedidos actualmente.
    
- **Database:** Una colección organizada de información o datos.
    
- **Data controller:** Una persona que determina el procedimiento y el propósito del procesamiento de datos.
    
- **Data custodian:** Cualquier persona o cosa responsable del manejo, transporte y almacenamiento seguro de la información.
    
- **Data exfiltration:** Transmisión no autorizada de datos desde un sistema.
    
- **Data in transit:** Datos que viajan de un punto a otro.
    
- **Data in use:** Datos que están siendo accedidos por uno o más usuarios.
    
- **Data owner:** La persona que decide quién puede acceder, editar, usar o destruir su información.
    
- **Data packet:** Una unidad básica de información que viaja de un dispositivo a otro dentro de una red.
    
- **Data point:** Una pieza específica de información.
    
- **Data processor:** Una persona responsable del procesamiento de datos en nombre del controlador de datos.
    
- **Data protection officer (DPO):** Un individuo responsable de monitorear el cumplimiento de los procedimientos de protección de datos de una organización.
    
- **Data type:** Una categoría para un tipo particular de elemento de datos (ej. `int`, `str`, `list`).
    
- **Date and time data:** Datos que representan una fecha y/o hora.
    
- **Debugger:** Una herramienta de software que ayuda a localizar el origen de un error y evaluar sus causas.
    
- **Debugging:** La práctica de identificar y corregir errores en el código.
    
- **Defense in depth:** Un enfoque en capas para la gestión de vulnerabilidades que reduce el riesgo.
    
- **Denial of service (DoS) attack:** Un ataque que apunta a una red o servidor y lo inunda con tráfico de red.
    
- **Detect:** Una función central de NIST relacionada con la identificación de posibles incidentes de seguridad y la mejora de las capacidades de monitoreo para aumentar la velocidad y eficiencia de las detecciones.
    
- **Detection:** El descubrimiento rápido de eventos de seguridad.
    
- **Dictionary data:** Datos que constan de uno o más pares clave-valor.
    
- **Digital certificate:** Un archivo que verifica la identidad del titular de una clave pública.
    
- **Digital forensics:** La práctica de recolectar y analizar datos para determinar qué ha sucedido después de un ataque.
    
- **Directory:** Un archivo que organiza dónde se almacenan otros archivos.
    
- **Disaster recovery plan:** Un plan que permite al equipo de seguridad de una organización delinear los pasos necesarios para minimizar el impacto de un incidente de seguridad.
    
- **Distributed denial of service (DDoS) attack:** Un tipo de ataque de denegación de servicio que utiliza múltiples dispositivos o servidores ubicados en diferentes lugares para inundar la red objetivo con tráfico no deseado.
    
- **Distributions:** Las diferentes versiones de Linux.
    
- **Documentation:** Cualquier forma de contenido grabado que se utiliza para un propósito específico.
    
- **DOM-based XSS attack:** Una instancia cuando un script malicioso existe en la página web que carga un navegador.
    
- **Domain Name System (DNS):** Un protocolo de red que traduce nombres de dominio de Internet en direcciones IP.
    
- **Dropper:** Un programa o archivo utilizado para instalar un rootkit en una computadora objetivo.

### E

- **Elevator pitch:** Un breve resumen de tu experiencia, habilidades y antecedentes.
    
- **Encapsulation:** Un proceso realizado por un servicio VPN que protege tus datos envolviendo datos sensibles en otros paquetes de datos.
    
- **Encryption:** El proceso de convertir datos de un formato legible a un formato codificado.
    
- **Endpoint:** Cualquier dispositivo conectado a una red.
    
- **Endpoint detection and response (EDR):** Una aplicación que monitorea un punto final en busca de actividad maliciosa.
    
- **Eradication:** La eliminación completa de los elementos del incidente de todos los sistemas afectados.
    
- **Escalation policy:** Un conjunto de acciones que describen quién debe ser notificado cuando ocurre una alerta de incidente y cómo debe manejarse ese incidente.
    
- **Event:** Una ocurrencia observable en una red, sistema o dispositivo.
    
- **Exception:** Un error que implica código que no se puede ejecutar aunque sea sintácticamente correcto.
    
- **Exclusive operator:** Un operador que no incluye el valor de comparación.
    
- **Exploit:** Una forma de aprovechar una vulnerabilidad.
    
- **Exposure:** Un error que puede ser explotado por una amenaza.
    
- **External threat:** Cualquier cosa fuera de la organización que tenga el potencial de dañar los activos organizacionales.

### F

- **False negative:** Un estado donde no se detecta la presencia de una amenaza.
    
- **False positive:** Una alerta que detecta incorrectamente la presencia de una amenaza.
    
- **Fileless malware:** Malware que no necesita ser instalado por el usuario porque utiliza programas legítimos que ya están instalados para infectar una computadora.
    
- **File path:** La ubicación de un archivo o directorio.
    
- **Filesystem Hierarchy Standard (FHS):** El componente del sistema operativo Linux que organiza los datos.
    
- **Filtering:** Seleccionar datos que coincidan con una determinada condición.
    
- **Final report:** Documentación que proporciona una revisión exhaustiva de un incidente.
    
- **Firewall:** Un dispositivo de seguridad de red que monitorea el tráfico hacia o desde una red.
    
- **Float data:** Datos que consisten en un número con un punto decimal.
    
- **Foreign key:** Una columna en una tabla que es una clave primaria en otra tabla.
    
- **Forward proxy server:** Un servidor que regula y restringe el acceso de una persona a Internet.
    
- **Function:** Una sección de código que se puede reutilizar en un programa.

### G

- **Global variable:** Una variable que está disponible en todo el programa.
    
- **Graphical user interface (GUI):** Una interfaz de usuario que utiliza iconos en la pantalla para gestionar diferentes tareas en la computadora.

### H

- **Hacker:** Cualquier persona o grupo que utiliza computadoras para obtener acceso no autorizado a datos.
    
- **Hacktivist:** Una persona que utiliza el hacking para lograr un objetivo político.
    
- **Hard drive:** Un componente de hardware utilizado para la memoria a largo plazo.
    
- **Hardware:** Los componentes físicos de una computadora.
    
- **Hash collision:** Una instancia cuando diferentes entradas producen el mismo valor hash.
    
- **Hash function:** Un algoritmo que produce un código que no se puede descifrar.
    
- **Hash table:** Una estructura de datos que se utiliza para almacenar y referenciar valores hash.
    
- **Health Insurance Portability and Accountability Act (HIPAA):** Una ley federal de EE. UU. establecida para proteger la información de salud de los pacientes.
    
- **Honeypot:** Un sistema o recurso creado como señuelo vulnerable a ataques con el propósito de atraer a posibles intrusos.
    
- **Host-based intrusion detection system (HIDS):** Una aplicación que monitorea la actividad del host en el que está instalada.
    
- **Hub:** Un dispositivo de red que transmite información a todos los dispositivos de la red.
    
- **Hypertext Transfer Protocol (HTTP):** Un protocolo de la capa de aplicación que proporciona un método de comunicación entre clientes y servidores de sitios web.
    
- **Hypertext Transfer Protocol Secure (HTTPS):** Un protocolo de red que proporciona un método seguro de comunicación entre clientes y servidores de sitios web.

### I

- **Identify:** Una función central de NIST relacionada con la gestión del riesgo de ciberseguridad y su efecto en las personas y activos de una organización.
    
- **Identity and access management (IAM):** Una colección de procesos y tecnologías que ayudan a las organizaciones a gestionar identidades digitales en su entorno.
    
- **IEEE 802.11 (Wi-Fi):** Un conjunto de estándares que definen la comunicación para redes LAN inalámbricas.
    
- **Immutable:** Un objeto que no se puede cambiar después de crearlo y asignarle un valor (ej. cadenas).
    
- **Implement:** El cuarto paso del NIST RMF que significa implementar planes de seguridad y privacidad para una organización.
    
- **Improper usage:** Un tipo de incidente que ocurre cuando un empleado de una organización viola las políticas de uso aceptable de la organización.
    
- **Incident:** Una ocurrencia que pone en peligro real o inminente, sin autoridad legal, la confidencialidad, integridad o disponibilidad de la información o un sistema de información; o constituye una violación o amenaza inminente de violación de la ley, políticas de seguridad, procedimientos de seguridad o políticas de uso aceptable.
    
- **Incident escalation:** El proceso de identificar un posible incidente de seguridad, triarlo y transferirlo a un miembro del equipo más experimentado.
    
- **Incident handler’s journal:** Una forma de documentación utilizada en la respuesta a incidentes.
    
- **Incident response:** El intento rápido de una organización para identificar un ataque, contener el daño y corregir los efectos de una brecha de seguridad.
    
- **Incident response plan:** Un documento que describe los procedimientos a seguir en cada paso de la respuesta a incidentes.
    
- **Inclusive operator:** Un operador que incluye el valor de comparación.
    
- **Indentation:** Espacio agregado al principio de una línea de código.
    
- **Index:** Un número asignado a cada elemento en una secuencia que indica su posición (comienza en 0).
    
- **Indicators of attack (IoA):** La serie de eventos observados que indican un incidente en tiempo real.
    
- **Indicators of compromise (IoC):** Evidencia observable que sugiere signos de un posible incidente de seguridad.
    
- **Information privacy:** La protección contra el acceso y distribución no autorizados de datos.
    
- **Information security (InfoSec):** La práctica de mantener los datos en todos los estados alejados de usuarios no autorizados.
    
- **Injection attack:** Código malicioso insertado en una aplicación vulnerable.
    
- **Input validation:** Programación que valida las entradas de usuarios y otros programas.
    
- **Integer data:** Datos que consisten en un número que no incluye un punto decimal.
    
- **Integrated development environment (IDE):** Una aplicación de software para escribir código que proporciona asistencia de edición y herramientas de corrección de errores.
    
- **Integrity:** La idea de que los datos son correctos, auténticos y confiables.
    
- **Internal hardware:** Los componentes necesarios para ejecutar la computadora.
    
- **Internal threat:** Un empleado actual o anterior, proveedor externo o socio de confianza que representa un riesgo de seguridad.
    
- **Internet Control Message Protocol (ICMP):** Un protocolo de Internet utilizado por los dispositivos para informarse mutuamente sobre errores de transmisión de datos en la red.
    
- **Internet Control Message Protocol flood (ICMP flood):** Un tipo de ataque DoS realizado por un atacante que envía repetidamente paquetes de solicitud ICMP a un servidor de red.
    
- **Internet Protocol (IP):** Un conjunto de estándares utilizados para enrutar y direccionar paquetes de datos mientras viajan entre dispositivos en una red.
    
- **Internet Protocol (IP) address:** Una cadena única de caracteres que identifica la ubicación de un dispositivo en Internet.
    
- **Interpreter:** Un programa de computadora que traduce el código Python en instrucciones ejecutables línea por línea.
    
- **Intrusion detection system (IDS):** Una aplicación que monitorea la actividad del sistema y alerta sobre posibles intrusiones.
    
- **Intrusion prevention system (IPS):** Una aplicación que monitorea la actividad del sistema en busca de actividad intrusiva y toma medidas para detener la actividad.
    
- **IP spoofing:** Un ataque de red realizado cuando un atacante cambia la IP de origen de un paquete de datos para hacerse pasar por un sistema autorizado y obtener acceso a una red.
    
- **Iterative statement:** Código que ejecuta repetidamente un conjunto de instrucciones (bucles `for`, `while`).

### K

- **KALI LINUX ™:** Una distribución de código abierto de Linux ampliamente utilizada en la industria de la seguridad.
    
- **Kernel:** El componente del sistema operativo Linux que gestiona procesos y memoria.
    
- **Key-value pair:** Un conjunto de datos que representa dos elementos vinculados: una clave y su valor correspondiente.

### L

- **Legacy operating system:** Un sistema operativo obsoleto pero que todavía se utiliza.
    
- **Lessons learned meeting:** Una reunión que incluye a todas las partes involucradas después de un incidente importante.
    
- **Library:** Una colección de módulos que proporcionan código al que los usuarios pueden acceder en sus programas.
    
- **Linux:** Un sistema operativo de código abierto.
    
- **List concatenation:** El concepto de combinar dos listas en una colocando los elementos de la segunda lista directamente después de los elementos de la primera lista.
    
- **List data:** Estructura de datos que consiste en una colección de datos en forma secuencial.
    
- **Loader:** Código malicioso que se lanza después de que un usuario inicia un programa dropper.
    
- **Local Area Network (LAN):** Una red que abarca áreas pequeñas como un edificio de oficinas, una escuela o un hogar.
    
- **Local variable:** Una variable asignada dentro de una función.
    
- **Log:** Un registro de eventos que ocurren dentro de los sistemas de una organización.
    
- **Log analysis:** El proceso de examinar registros para identificar eventos de interés.
    
- **Logging:** El registro de eventos que ocurren en sistemas informáticos y redes.
    
- **Logic error:** Un error que resulta cuando la lógica utilizada en el código produce resultados no deseados.
    
- **Log management:** El proceso de recolectar, almacenar, analizar y eliminar datos de registro.
    
- **Loop condition:** La parte de un bucle que determina cuándo termina el bucle.
    
- **Loop variable:** Una variable que se utiliza para controlar las iteraciones de un bucle.

### M

- **Malware:** Software diseñado para dañar dispositivos o redes.
    
- **Malware infection:** Un tipo de incidente que ocurre cuando un software malicioso diseñado para interrumpir un sistema se infiltra en las computadoras o la red de una organización.
    
- **Media Access Control (MAC) address:** Un identificador alfanumérico único asignado a cada dispositivo físico en una red.
    
- **Method:** Una función que pertenece a un tipo de datos específico (ej. `.upper()` para cadenas).
    
- **Metrics:** Atributos técnicos clave como tiempo de respuesta, disponibilidad y tasa de fallos, utilizados para evaluar el rendimiento de una aplicación de software.
    
- **MITRE:** Una colección de centros de investigación y desarrollo sin fines de lucro.
    
- **Modem:** Un dispositivo que conecta tu router a Internet y lleva el acceso a Internet a la LAN.
    
- **Module:** Un archivo de Python que contiene funciones, variables, clases y cualquier tipo de código ejecutable adicional.
    
- **Monitor:** El séptimo paso del NIST RMF que significa estar al tanto de cómo operan los sistemas.
    
- **Multi-factor authentication (MFA):** Una medida de seguridad que requiere que un usuario verifique su identidad de dos o más formas para acceder a un sistema o red.

### N

- **nano:** Un editor de archivos de línea de comandos disponible por defecto en muchas distribuciones de Linux.
    
- **National Institute of Standards and Technology (NIST) Cybersecurity Framework (CSF):** Un marco voluntario que consiste en estándares, directrices y mejores prácticas para gestionar el riesgo de ciberseguridad.
    
- **National Institute of Standards and Technology (NIST) Incident Response Lifecycle:** Un marco para la respuesta a incidentes que consta de cuatro fases: Preparación; Detección y Análisis; Contención, Erradicación y Recuperación; y Actividad posterior al incidente.
    
- **National Institute of Standards and Technology (NIST) Special Publication (S.P.) 800-53:** Un marco unificado para proteger la seguridad de los sistemas de información dentro del gobierno federal de EE. UU.
    
- **Network:** Un grupo de dispositivos conectados.
    
- **Network-based intrusion detection system (NIDS):** Una aplicación que recopila y monitorea el tráfico de red y los datos de la red.
    
- **Network data:** Los datos que se transmiten entre dispositivos en una red.
    
- **Network Interface Card (NIC):** Hardware que conecta computadoras a una red.
    
- **Network log analysis:** El proceso de examinar los registros de red para identificar eventos de interés.
    
- **Network protocol analyzer (packet sniffer):** Una herramienta diseñada para capturar y analizar el tráfico de datos dentro de una red.
    
- **Network protocols:** Un conjunto de reglas utilizadas por dos o más dispositivos en una red para describir el orden de entrega y la estructura de los datos.
    
- **Network security:** La práctica de mantener segura la infraestructura de red de una organización contra el acceso no autorizado.
    
- **Network segmentation:** Una técnica de seguridad que divide la red en segmentos.
    
- **Network traffic:** La cantidad de datos que se mueven a través de una red.
    
- **Non-repudiation:** El concepto de que la autenticidad de la información no puede ser negada.
    
- **Notebook:** Una interfaz en línea para escribir, almacenar y ejecutar código.
    
- **Numeric data:** Datos que consisten en números.
    

---

### O

- **OAuth:** Un protocolo de autorización de estándar abierto que comparte acceso designado entre aplicaciones.
    
- **Object:** Un tipo de datos que almacena datos en una lista separada por comas de pares clave-valor. (_Nota: Esta definición parece más adecuada para un diccionario o JSON. Un objeto en Python es una instancia de una clase._)
    
- **On-path attack:** Un ataque donde un actor malicioso se coloca en medio de una conexión autorizada e intercepta o altera los datos en tránsito.
    
- **Open-source intelligence (OSINT):** La recolección y análisis de información de fuentes públicamente disponibles para generar inteligencia utilizable.
    
- **Open systems interconnection (OSI) model:** Un concepto estandarizado que describe las siete capas que utilizan las computadoras para comunicarse y enviar datos a través de la red.
    
- **Open Web Application Security Project (OWASP):** Una organización sin fines de lucro enfocada en mejorar la seguridad del software.
    
- **Operating system (OS):** La interfaz entre el hardware de la computadora y el usuario.
    
- **Operator:** Un símbolo o palabra clave que representa una operación.
    
- **Options:** Entrada que modifica el comportamiento de un comando.
    
- **Order of volatility:** Una secuencia que describe el orden de los datos que deben preservarse desde el primero hasta el último.
    
- **OWASP Top 10:** Un documento de concienciación estándar reconocido mundialmente que enumera los 10 riesgos de seguridad más críticos para las aplicaciones web.
    

---

### P

- **Package:** Una pieza de software que se puede combinar con otros paquetes para formar una aplicación.
    
- **Package manager:** Una herramienta que ayuda a los usuarios a instalar, gestionar y eliminar paquetes o aplicaciones.
    
- **Packet capture (P-cap):** Un archivo que contiene paquetes de datos interceptados desde una interfaz o red.
    
- **Packet sniffing:** La práctica de capturar e inspeccionar paquetes de datos a través de una red.
    
- **Parameter (Python):** Un objeto que se incluye en una definición de función para su uso en esa función.
    
- **Parrot:** Una distribución de código abierto comúnmente utilizada para seguridad.
    
- **Parsing:** El proceso de convertir datos a un formato más legible.
    
- **Passive packet sniffing:** Un tipo de ataque donde un actor malicioso se conecta a un concentrador de red y observa todo el tráfico en la red.
    
- **Password attack:** Un intento de acceder a dispositivos, sistemas, redes o datos protegidos por contraseña.
    
- **Patch update:** Una actualización de software y sistema operativo que aborda vulnerabilidades de seguridad dentro de un programa o producto.
    
- **Payment Card Industry Data Security Standards (PCI DSS):** Cualquier dato de titular de tarjeta que una organización acepta, transmite o almacena.
    
- **Penetration test (pen test):** Un ataque simulado que ayuda a identificar vulnerabilidades en sistemas, redes, sitios web, aplicaciones y procesos.
    
- **PEP 8 style guide:** Un recurso que proporciona pautas estilísticas para programadores que trabajan en Python.
    
- **Peripheral devices:** Componentes de hardware que están conectados y controlados por el sistema informático.
    
- **Permissions:** El tipo de acceso otorgado para un archivo o directorio.
    
- **Personally identifiable information (PII):** Cualquier información utilizada para inferir la identidad de un individuo.
    
- **Phishing:** El uso de comunicaciones digitales para engañar a las personas para que revelen datos sensibles o desplieguen software malicioso.
    
- **Phishing kit:** Una colección de herramientas de software necesarias para lanzar una campaña de phishing.
    
- **Physical attack:** Un incidente de seguridad que afecta no solo a entornos digitales sino también físicos donde se despliega el incidente.
    
- **Physical social engineering:** Un ataque en el que un actor de amenazas se hace pasar por un empleado, cliente o proveedor para obtener acceso no autorizado a una ubicación física.
    
- **Ping of death:** Un tipo de ataque DoS causado cuando un hacker hace ping a un sistema enviándole un paquete ICMP sobredimensionado que es más grande que 64KB.
    
- **Playbook:** Un manual que proporciona detalles sobre cualquier acción operativa.
    
- **Policy:** Un conjunto de reglas que reducen el riesgo y protegen la información.
    
- **Port:** Una ubicación basada en software que organiza el envío y recepción de datos entre dispositivos en una red.
    
- **Port filtering:** Una función de firewall que bloquea o permite ciertos números de puerto para limitar la comunicación no deseada.
    
- **Post-incident activity:** El proceso de revisar un incidente para identificar áreas de mejora durante el manejo de incidentes.
    
- **Potentially unwanted application (PUA):** Un tipo de software no deseado que se incluye con programas legítimos y que puede mostrar anuncios, causar ralentización del dispositivo o instalar otro software.
    
- **Private data:** Información que debe mantenerse alejada del público.
    
- **Prepare:** El primer paso del NIST RMF relacionado con actividades necesarias para gestionar riesgos de seguridad y privacidad antes de que ocurra una brecha.
    
- **Prepared statement:** Una técnica de codificación que ejecuta sentencias SQL antes de pasarlas a una base de datos.
    
- **Primary key:** Una columna donde cada fila tiene una entrada única.
    
- **Principle of least privilege:** El concepto de otorgar solo el acceso y la autorización mínimos requeridos para completar una tarea o función.
    
- **Privacy protection:** El acto de salvaguardar la información personal del uso no autorizado.
    
- **Procedures:** Instrucciones paso a paso para realizar una tarea de seguridad específica.
    
- **Process of Attack Simulation and Threat Analysis (PASTA):** Un popular marco de modelado de amenazas utilizado en muchas industrias.
    
- **Programming:** Un proceso que se puede utilizar para crear un conjunto específico de instrucciones para que una computadora ejecute tareas.
    
- **Protect:** Una función central de NIST utilizada para proteger una organización mediante la implementación de políticas, procedimientos, capacitación y herramientas que ayudan a mitigar las amenazas de ciberseguridad.
    
- **Protected health information (PHI):** Información que se relaciona con la salud o condición física o mental pasada, presente o futura de un individuo.
    
- **Protecting and preserving evidence:** El proceso de trabajar adecuadamente con evidencia digital frágil y volátil.
    
- **Proxy server:** Un servidor que cumple las solicitudes de sus clientes reenviándolas a otros servidores.
    
- **Public data:** Datos que ya son accesibles al público y presentan un riesgo mínimo para la organización si son vistos o compartidos por otros.
    
- **Public key infrastructure (PKI):** Un marco de cifrado que asegura el intercambio de información en línea.
    
- **Python Standard Library:** Una extensa colección de código Python que a menudo viene empaquetada con Python.
    

---

### Q

- **Query:** Una solicitud de datos de una tabla de base de datos o una combinación de tablas.
    
- **Quid pro quo:** Un tipo de cebo utilizado para engañar a alguien haciéndole creer que será recompensado a cambio de compartir acceso, información o dinero.
    

---

### R

- **Rainbow table:** Un archivo de valores hash pregenerados y su texto plano asociado.
    
- **Random Access Memory (RAM):** Un componente de hardware utilizado para la memoria a corto plazo.
    
- **Ransomware:** Un ataque malicioso donde los actores de amenazas cifran los datos de una organización y exigen un pago para restaurar el acceso.
    
- **Rapport:** Una relación amistosa en la que las personas involucradas entienden las ideas de los demás y se comunican bien entre sí.
    
- **Recover:** Una función central de NIST relacionada con el retorno de los sistemas afectados a la operación normal.
    
- **Recovery:** El proceso de devolver los sistemas afectados a las operaciones normales.
    
- **Red Hat® Enterprise Linux® (también referido simplemente como Red Hat en este curso):** Una distribución de Linux basada en suscripción construida para uso empresarial.
    
- **Reflected XSS attack:** Una instancia cuando un script malicioso se envía a un servidor y se activa durante la respuesta del servidor.
    
- **Regular expression (regex):** Una secuencia de caracteres que forma un patrón.
    
- **Regulations:** Reglas establecidas por un gobierno u otra autoridad para controlar la forma en que se hace algo.
    
- **Relational database:** Una base de datos estructurada que contiene tablas relacionadas entre sí.
    
- **Relative file path:** Una ruta de archivo que comienza desde el directorio actual del usuario.
    
- **Replay attack:** Un ataque de red realizado cuando un actor malicioso intercepta un paquete de datos en tránsito y lo retrasa o lo repite en otro momento.
    
- **Resiliency:** La capacidad de prepararse, responder y recuperarse de interrupciones.
    
- **Respond:** Una función central de NIST relacionada con asegurarse de que se utilicen los procedimientos adecuados para contener, neutralizar y analizar incidentes de seguridad, e implementar mejoras en el proceso de seguridad.
    
- **Return statement:** Una declaración de Python que se ejecuta dentro de una función y envía información de vuelta a la llamada a la función.
    
- **Reverse proxy server:** Un servidor que regula y restringe el acceso de Internet a un servidor interno.
    
- **Risk:** Cualquier circunstancia o evento que pueda impactar negativamente la confidencialidad, integridad o disponibilidad de un activo.
    
- **Risk mitigation:** El proceso de tener los procedimientos y reglas correctos para reducir rápidamente el impacto de un riesgo como una brecha.
    
- **Root directory:** El directorio de más alto nivel en Linux.
    
- **Rootkit:** Malware que proporciona acceso administrativo remoto a una computadora.
    
- **Root user (or superuser):** Un usuario con privilegios elevados para modificar el sistema.
    
- **Router:** Un dispositivo de red que conecta múltiples redes juntas.
    

---

### S

- **Salting:** Una salvaguarda adicional utilizada para fortalecer las funciones hash.
    
- **Scareware:** Malware que emplea tácticas para asustar a los usuarios para que infecten su dispositivo.
    
- **Search Processing Language (SPL):** El lenguaje de consulta de Splunk.
    
- **Secure File Transfer Protocol (SFTP):** Un protocolo seguro utilizado para transferir archivos de un dispositivo a otro a través de una red.
    
- **Secure shell (SSH):** Un protocolo de seguridad utilizado para crear un shell con un sistema remoto.
    
- **Security architecture:** Un tipo de diseño de seguridad compuesto por múltiples componentes, como herramientas y procesos, utilizados para proteger una organización de riesgos y amenazas externas.
    
- **Security audit:** Una revisión de los controles, políticas y procedimientos de seguridad de una organización frente a un conjunto de expectativas.
    
- **Security controls:** Salvaguardas diseñadas para reducir riesgos de seguridad específicos.
    
- **Security ethics:** Directrices para tomar decisiones apropiadas como profesional de la seguridad.
    
- **Security frameworks:** Directrices utilizadas para construir planes que ayuden a mitigar riesgos y amenazas a datos y privacidad.
    
- **Security governance:** Prácticas que ayudan a apoyar, definir y dirigir los esfuerzos de seguridad de una organización.
    
- **Security hardening:** El proceso de fortalecer un sistema para reducir sus vulnerabilidades y superficie de ataque.
    
- **Security information and event management (SIEM):** Una aplicación que recopila y analiza datos de registro para monitorear actividades críticas en una organización.
    
- **Security mindset:** La capacidad de evaluar riesgos y buscar e identificar constantemente la brecha potencial o real de un sistema, aplicación o dato.
    
- **Security operations center (SOC):** Una unidad organizacional dedicada a monitorear redes, sistemas y dispositivos en busca de amenazas o ataques de seguridad.
    
- **Security orchestration, automation, and response (SOAR):** Una colección de aplicaciones, herramientas y flujos de trabajo que utilizan la automatización para responder a eventos de seguridad.
    
- **Security posture:** La capacidad de una organización para gestionar su defensa de activos y datos críticos y reaccionar al cambio.
    
- **Security zone:** Un segmento de la red de una empresa que protege la red interna de Internet.
    
- **Select:** El tercer paso del NIST RMF que significa elegir, personalizar y capturar documentación de los controles que protegen una organización.
    
- **Sensitive data:** Un tipo de datos que incluye información de identificación personal (PII), información de identificación personal sensible (SPII) o información de salud protegida (PHI).
    
- **Sensitive personally identifiable information (SPII):** Un tipo específico de PII que cae bajo directrices de manejo más estrictas.
    
- **Separation of duties:** El principio de que a los usuarios no se les deben dar niveles de autorización que les permitan hacer un mal uso de un sistema.
    
- **Session:** Una secuencia de solicitudes y respuestas HTTP de red asociadas con el mismo usuario.
    
- **Session cookie:** Un token que los sitios web utilizan para validar una sesión y determinar cuánto debe durar esa sesión.
    
- **Session hijacking:** Un evento cuando los atacantes obtienen el ID de sesión de un usuario legítimo.
    
- **Session ID:** Un token único que identifica a un usuario y su dispositivo mientras accede a un sistema.
    
- **Set data:** Datos que consisten en una colección desordenada de valores únicos. (_Nota: "Set data" se traduce mejor como "Datos de conjunto"_).
    
- **Shared responsibility:** La idea de que todos los individuos dentro de una organización toman un papel activo en la reducción del riesgo y el mantenimiento de la seguridad tanto física como virtual.
    
- **Shell:** El intérprete de línea de comandos.
    
- **Signature:** Un patrón asociado con actividad maliciosa.
    
- **Signature analysis:** Un método de detección utilizado para encontrar eventos de interés.
    
- **Simple Network Management Protocol (SNMP):** Un protocolo de red utilizado para monitorear y gestionar dispositivos en una red.
    
- **Single sign-on (SSO):** Una tecnología que combina varios inicios de sesión diferentes en uno solo.
    
- **Smishing:** El uso de mensajes de texto para engañar a los usuarios para obtener información sensible o para hacerse pasar por una fuente conocida.
    
- **Smurf attack:** Un ataque de red realizado cuando un atacante olfatea la dirección IP de un usuario autorizado y la inunda con paquetes ICMP.
    
- **Social engineering:** Una técnica de manipulación que explota el error humano para obtener información privada, acceso o objetos de valor.
    
- **Social media phishing:** Un tipo de ataque donde un actor de amenazas recopila información detallada sobre su objetivo en sitios de redes sociales antes de iniciar el ataque.
    
- **Spear phishing:** Un ataque de correo electrónico malicioso dirigido a un usuario o grupo de usuarios específico, que parece originarse de una fuente confiable.
    
- **Speed:** La velocidad a la que un dispositivo envía y recibe datos, medida en bits por segundo.
    
- **Splunk Cloud:** Una herramienta alojada en la nube utilizada para recopilar, buscar y monitorear datos de registro.
    
- **Splunk Enterprise:** Una herramienta autoalojada utilizada para retener, analizar y buscar datos de registro de una organización para proporcionar información y alertas de seguridad en tiempo real.
    
- **Spyware:** Malware utilizado para recopilar y vender información sin consentimiento.
    
- **SQL (Structured Query Language):** Un lenguaje de programación utilizado para crear, interactuar y solicitar información de una base de datos.
    
- **SQL injection:** Un ataque que ejecuta consultas inesperadas en una base de datos.
    
- **Stakeholder:** Un individuo o grupo que tiene interés en cualquier decisión o actividad de una organización.
    
- **Standard error:** Un mensaje de error devuelto por el sistema operativo a través del shell.
    
- **Standard input:** Información recibida por el sistema operativo a través de la línea de comandos.
    
- **Standard output:** Información devuelta por el sistema operativo a través del shell.
    
- **Standards:** Referencias que informan cómo establecer políticas.
    
- **STAR method:** Una técnica de entrevista utilizada para responder preguntas conductuales y situacionales.
    
- **Stateful:** Una clase de firewall que realiza un seguimiento de la información que pasa a través de él y filtra proactivamente las amenazas.
    
- **Stateless:** Una clase de firewall que opera en base a reglas predefinidas y que no realiza un seguimiento de la información de los paquetes de datos.
    
- **Stored XSS attack:** Una instancia cuando un script malicioso se inyecta directamente en el servidor.
    
- **String concatenation:** El proceso de unir dos cadenas.
    
- **String data:** Datos que consisten en una secuencia ordenada de caracteres.
    
- **Style guide:** Un manual que informa la redacción, el formato y el diseño de documentos.
    
- **Subnetting:** La subdivisión de una red en grupos lógicos llamados subredes.
    
- **Substring:** Una secuencia continua de caracteres dentro de una cadena.
    
- **Sudo:** Un comando que otorga temporalmente permisos elevados a usuarios específicos.
    
- **Supply-chain attack:** Un ataque que apunta a sistemas, aplicaciones, hardware y/o software para localizar una vulnerabilidad donde se pueda desplegar malware.
    
- **Suricata:** Un sistema de detección de intrusiones de código abierto, sistema de prevención de intrusiones y herramienta de análisis de red.
    
- **Switch:** Un dispositivo que realiza conexiones entre dispositivos específicos en una red enviando y recibiendo datos entre ellos.
    
- **Symmetric encryption:** El uso de una única clave secreta para intercambiar información.
    
- **Synchronize (SYN) flood attack:** Un tipo de ataque DoS que simula una conexión TCP/IP e inunda un servidor con paquetes SYN.
    
- **Syntax:** Las reglas que determinan lo que está correctamente estructurado en un lenguaje informático.
    
- **Syntax error:** Un error que implica el uso no válido de un lenguaje de programación.

### T

- **Tailgating:** Una táctica de ingeniería social en la que personas no autorizadas siguen a una persona autorizada a un área restringida.
    
- **TCP/IP model:** Un marco utilizado para visualizar cómo se organizan y transmiten los datos a través de una red.
    
- **tcpdump:** Un analizador de protocolos de red de línea de comandos.
    
- **Technical skills:** Habilidades que requieren conocimiento de herramientas, procedimientos y políticas específicas.
    
- **Telemetry:** La recolección y transmisión de datos para análisis.
    
- **Threat:** Cualquier circunstancia o evento que pueda impactar negativamente los activos.
    
- **Threat actor:** Cualquier persona o grupo que presenta un riesgo de seguridad.
    
- **Threat hunting:** La búsqueda proactiva de amenazas en una red.
    
- **Threat intelligence:** Información sobre amenazas basada en evidencia que proporciona contexto sobre amenazas existentes o emergentes.
    
- **Threat modeling:** El proceso de identificar activos, sus vulnerabilidades y cómo cada uno está expuesto a amenazas.
    
- **Transferable skills:** Habilidades de otras áreas que pueden aplicarse a diferentes carreras.
    
- **Transmission Control Protocol (TCP):** Un protocolo de comunicación de Internet que permite a dos dispositivos formar una conexión y transmitir datos.
    
- **Triage:** La priorización de incidentes según su nivel de importancia o urgencia.
    
- **Trojan horse:** Malware que se parece a un archivo o programa legítimo.
    
- **True negative:** Un estado donde no hay detección de actividad maliciosa.
    
- **True positive:** Una alerta que detecta correctamente la presencia de un ataque.
    
- **Tuple data:** Datos que consisten en una colección de datos que no se pueden cambiar. (_Nota: "Tuple data" se traduce mejor como "Datos de tupla"_).
    
- **Type error:** Un error que resulta del uso del tipo de datos incorrecto.
    

---

### U

- **Ubuntu:** Una distribución de código abierto y fácil de usar ampliamente utilizada en seguridad y otras industrias.
    
- **Unauthorized access:** Un tipo de incidente que ocurre cuando un individuo obtiene acceso digital o físico a un sistema o aplicación sin permiso.
    
- **Uncontrolled zone:** Cualquier red fuera del control de tu organización.
    
- **Unified Extensible Firmware Interface (UEFI):** Un microchip que contiene instrucciones de carga para la computadora y reemplaza al BIOS en sistemas más modernos.
    
- **USB baiting:** Un ataque en el que un actor de amenazas deja estratégicamente una memoria USB con malware para que un empleado la encuentre e instale para infectar una red sin saberlo.
    
- **User:** La persona que interactúa con una computadora.
    
- **User Datagram Protocol (UDP):** Un protocolo sin conexión que no establece una conexión entre dispositivos antes de las transmisiones.
    
- **User-defined function:** Una función que los programadores diseñan para sus necesidades específicas.
    
- **User interface:** Un programa que permite al usuario controlar las funciones del sistema operativo.
    
- **User provisioning:** El proceso de crear y mantener la identidad digital de un usuario.
    

---

### V

- **Variable:** Un contenedor que almacena datos.
    
- **Virtual Private Network (VPN):** Un servicio de seguridad de red que cambia tu dirección IP pública y oculta tu ubicación virtual para que puedas mantener tus datos privados cuando utilizas una red pública como Internet.
    
- **Virus:** Código malicioso escrito para interferir con las operaciones de la computadora y causar daño a datos y software.
    
- **VirusTotal:** Un servicio que permite a cualquier persona analizar archivos, dominios, URL y direcciones IP sospechosos en busca de contenido malicioso.
    
- **Vishing:** La explotación de la comunicación de voz electrónica para obtener información sensible o para hacerse pasar por una fuente conocida.
    
- **Visual dashboard:** Una forma de mostrar varios tipos de datos rápidamente en un solo lugar.
    
- **Vulnerability:** Una debilidad que puede ser explotada por una amenaza.
    
- **Vulnerability assessment:** El proceso de revisión interna de los sistemas de seguridad de una organización.
    
- **Vulnerability management:** El proceso de encontrar y parchear vulnerabilidades.
    
- **Vulnerability scanner:** Software que compara automáticamente las vulnerabilidades y exposiciones comunes existentes con las tecnologías en la red.
    

---

### W

- **Watering hole attack:** Un tipo de ataque cuando un actor de amenazas compromete un sitio web frecuentemente visitado por un grupo específico de usuarios.
    
- **Web-based exploits:** Código o comportamiento malicioso utilizado para aprovechar fallos de codificación en una aplicación web.
    
- **Whaling:** Una categoría de intentos de spear phishing dirigidos a ejecutivos de alto rango en una organización.
    
- **Wide Area Network (WAN):** Una red que abarca una gran área geográfica como una ciudad, estado o país.
    
- **Wi-Fi Protected Access (WPA):** Un protocolo de seguridad inalámbrico para que los dispositivos se conecten a Internet.
    
- **Wildcard:** Un carácter especial que puede sustituirse por cualquier otro carácter.
    
- **Wireshark:** Un analizador de protocolos de red de código abierto.
    
- **World-writable file:** Un archivo que puede ser alterado por cualquier persona en el mundo.
    
- **Worm:** Malware que puede duplicarse y propagarse a través de sistemas por sí solo.
    

---

### Y

- **YARA-L:** Un lenguaje informático utilizado para crear reglas para buscar a través de datos de registro ingeridos.
    

---

### Z

- **Zero-day:** Un exploit que era previamente desconocido.
