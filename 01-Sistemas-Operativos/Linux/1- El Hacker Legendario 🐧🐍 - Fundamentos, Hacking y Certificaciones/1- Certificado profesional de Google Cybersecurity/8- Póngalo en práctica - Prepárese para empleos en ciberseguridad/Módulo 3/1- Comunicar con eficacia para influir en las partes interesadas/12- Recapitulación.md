# Recapitulación

### 💡 Puntos Clave de este Módulo

- **Identificar a la Audiencia:** Aprendiste a reconocer a las partes interesadas clave (como el CISO, CFO, Gerentes de Operaciones) y a entender qué es lo que más les importa a cada uno.
    
- **Adaptar el Mensaje:** La comunicación debe ser precisa, relevante y **evitar detalles técnicos innecesarios**. El objetivo es facilitarles el trabajo a personas muy ocupadas.
    
- **Elegir la Estrategia Correcta:** Viste _cómo_ comunicarte, sabiendo cuándo usar:
    
    - **Paneles Visuales:** Para contar una historia con datos y métricas (como el ejercicio de Google Sheets).
        
    - **Correos Electrónicos:** Para documentación formal (manejándolos siempre como información sensible).
        
    - **Llamadas/Mensajes:** Para asuntos urgentes que no pueden esperar una respuesta por correo.
