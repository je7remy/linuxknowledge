# Conclusión del curso

## fundamentals Fundamentos de Python

- Sentamos las bases discutiendo **variables**, **tipos de datos** (cadenas, enteros, flotantes, booleanos, listas), **sentencias condicionales** (`if`, `elif`, `else`) y **sentencias iterativas** (bucles `for` y `while`).
    

---

## ⚙️ Escribir Código Python Eficaz

- Aprendimos sobre **funciones** para mejorar la eficiencia y reutilización del código, explorando tanto las **integradas** como creando nuestras propias **funciones definidas por el usuario** (`def`, `return`).
    
- Descubrimos los **módulos y bibliotecas** (`import`), que nos dan acceso a funciones y variables preempaquetadas para facilitar el trabajo.
    
- Discutimos la importancia de la **legibilidad del código** y las guías de estilo (como PEP 8).
    

---

## ⛓️ Trabajo con Cadenas y Listas

- Profundizamos en **métodos** específicos para manipular cadenas (`.upper()`, `.lower()`, `.index()`, `.split()`) y listas (`.append()`, `.insert()`, `.remove()`, `.index()`).
    
- Practicamos el uso de **índices** y **cortes (slicing)** para extraer información precisa.
    
- Combinamos estos conceptos para escribir un **algoritmo sencillo**.
    
- Exploramos las **expresiones regulares (regex)** y el módulo `re` para encontrar patrones en cadenas.
    

---

## 🛠️ Poner Python en Práctica

- Aprendimos cómo **abrir**, **leer** (`with open()`, `.read()`) y **analizar sintácticamente (parsear)** archivos (`.split()`, `.join()`, `.write()`), habilidades esenciales para trabajar con **archivos de registro**.
    
- Cubrimos estrategias para **depurar código**, identificando y corrigiendo errores de sintaxis, lógicos y excepciones.
