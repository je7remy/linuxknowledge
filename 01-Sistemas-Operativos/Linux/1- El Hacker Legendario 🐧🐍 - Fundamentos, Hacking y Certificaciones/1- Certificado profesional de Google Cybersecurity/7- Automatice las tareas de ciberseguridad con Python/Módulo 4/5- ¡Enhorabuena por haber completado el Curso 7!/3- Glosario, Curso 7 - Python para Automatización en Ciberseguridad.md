# Glosario, Curso 7 - Python para Automatización en Ciberseguridad

## 📖 Glosario: Curso 7 - Python para Automatización en Ciberseguridad

### A

- **Algoritmo:** Un conjunto de reglas que resuelven un problema.
    
- **Análisis (Parsing):** El proceso de convertir datos a un formato más legible.
    
- **Argumento (Python):** Los datos que se introducen en una función cuando se llama.
    
- **Automatización:** El uso de la tecnología para reducir el esfuerzo humano y manual para realizar tareas comunes y repetitivas.
    

---

### B

- **Biblioteca:** Una colección de módulos que proporcionan código al que los usuarios pueden acceder en sus programas.
    
- **Biblioteca estándar de Python:** Una extensa colección de código Python que a menudo viene empaquetada con Python.
    
- **Bucle (Variable de):** Una variable que se usa para controlar las iteraciones de un bucle.
    

---

### C

- **Comentario:** Una nota que hacen los programadores sobre la intención detrás de su código.
    
- **Concatenación de cadenas:** El proceso de unir dos cadenas.
    
- **Concatenación de listas:** El concepto de combinar dos listas en una colocando los elementos de la segunda lista directamente después de los elementos de la primera lista.
    

---

### D

- **Datos booleanos:** Datos que solo pueden ser uno de dos valores: `True` o `False`.
    
- **Datos de cadena:** Datos que consisten en una secuencia ordenada de caracteres.
    
- **Datos de diccionario:** Datos que constan de uno o más pares clave-valor.
    
- **Datos de lista:** Estructura de datos que consiste en una colección de datos en forma secuencial.
    
- **Datos de tupla:** Estructura de datos que consiste en una colección de datos que no se pueden cambiar.
    
- **Datos enteros:** Datos que consisten en un número que no incluye un punto decimal.
    
- **Datos flotantes:** Datos que consisten en un número con un punto decimal.
    
- **Depurador:** Una herramienta de software que ayuda a localizar el origen de un error y evaluar sus causas.
    
- **Depuración:** La práctica de identificar y corregir errores en el código.
    

---

### E

- **Entorno de desarrollo integrado (IDE):** Una aplicación de software para escribir código que proporciona asistencia de edición y herramientas de corrección de errores.
    
- **Error de sintaxis:** Un error que implica el uso no válido de un lenguaje de programación.
    
- **Error de tipo:** Un error que resulta del uso del tipo de datos incorrecto.
    
- **Error lógico:** Un error que se produce cuando la lógica utilizada en el código produce resultados no deseados.
    
- **Establecer datos (Set data):** Datos que consisten en una colección desordenada de valores únicos. (_Nota: "Set data" se traduce mejor como "Datos de conjunto"_).
    
- **Excepción:** Un error que implica código que no se puede ejecutar aunque sea sintácticamente correcto.
    
- **Expresión regular (regex):** Una secuencia de caracteres que forma un patrón.
    

---

### F

- **Función:** Una sección de código que se puede reutilizar en un programa.
    
- **Función definida por el usuario:** Una función que los programadores diseñan para sus necesidades específicas.
    
- **Función incorporada (Built-in):** Una función que existe dentro de Python y se puede llamar directamente.
    

---

### G

- **Guía de estilo:** Un manual que informa la redacción, el formato y el diseño de documentos.
    
- **Guía de estilo PEP 8:** Un recurso que proporciona pautas estilísticas para programadores que trabajan en Python.
    

---

### I

- **Inmutable:** Un objeto que no se puede cambiar después de crearlo y asignarle un valor.
    
- **Índice:** Un número asignado a cada elemento de una secuencia que indica su posición (comienza en 0).
    
- **Instrucción condicional:** Instrucción que evalúa el código para determinar si cumple un conjunto especificado de condiciones (`if`, `elif`, `else`).
    
- **Instrucción iterativa:** Código que ejecuta repetidamente un conjunto de instrucciones (bucles `for`, `while`).
    
- **Interfaz de línea de comandos:** Una interfaz de usuario basada en texto que usa comandos para interactuar con el equipo.
    
- **Intérprete:** Un programa de computadora que traduce el código Python en instrucciones ejecutables línea por línea.
    

---

### M

- **Método:** Una función que pertenece a un tipo de datos específico (ej. `.upper()` para cadenas).
    
- **Módulo:** Un archivo de Python que contiene funciones, variables, clases y cualquier tipo de código ejecutable adicional.
    

---

### N

- **Notación entre corchetes:** Los índices colocados entre corchetes `[]` para acceder a elementos o rebanadas.
    
- **Notebook:** Una interfaz en línea para escribir, almacenar y ejecutar código.
    

---

### P

- **Parámetro (Python):** Un objeto que se incluye en una definición de función para su uso en esa función.
    
- **Programación:** Un proceso que se puede utilizar para crear un conjunto específico de instrucciones para que una computadora ejecute tareas.
    

---

### R

- **Registro:** Un registro de eventos que ocurren dentro de los sistemas de una organización.
    
- **Ruta de acceso del archivo:** La ubicación de un archivo o directorio.
    

---

### S

- **Sangría:** Espacio agregado al principio de una línea de código, crucial para la estructura en Python.
    
- **Sentencia `return`:** Una declaración de Python que se ejecuta dentro de una función y envía información a la llamada a la función.
    
- **Sintaxis:** Las reglas que determinan lo que está correctamente estructurado en un lenguaje informático.
    
- **Subcadena:** Una secuencia continua de caracteres dentro de una cadena.
    

---

### T

- **Tipo de datos:** Una categoría para un tipo particular de elemento de datos (ej. `int`, `str`, `list`).
    

---

### V

- **Variable:** Un contenedor que almacena datos.
    
- **Variable global:** Una variable que está disponible en todo el programa.
    
- **Variable local:** Una variable asignada dentro de una función.
