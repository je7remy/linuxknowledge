## Patrón Karpathy aplicado

Este vault implementa el patrón **LLM Wiki** de Andrej Karpathy:

- **Wiki maintained**: cada nota tiene cross-references curadas, no es solo
  almacén de markdown plano.
- **Schema explícito**: [[schema]] define las convenciones.
- **Instrucciones operativas**: [[CLAUDE]] define cómo el LLM hace
  ingest/query/lint.
- **Index content-oriented**: este archivo (catálogo de páginas).
- **Log chronological greppable**: [[log]] con formato `## [YYYY-MM-DD] op | Título`.
- **Hub central**: [[🔒🐧Hub]] como nodo del que todo es alcanzable en ≤3 saltos.
- **Persistente y acumulativo**: cada ingest enriquece el grafo en lugar de
  re-derivar desde cero.
